# Kasane Context Navigation Protocol

Этот навык предназначен для быстрого и экономного входа в любую задачу по проекту Kasane (Android & Linux Desktop).

## Протокол действий агента

1. **Изучи базовые правила**:
   - Быстро сверься с контрактом в `AGENTS.md`. Помни: нулевой `unwrap()` в рантайме, сохранять локальную независимость воспроизведения.

2. **Определи целевую платформу**:
   - **Android**: задачи, затрагивающие Kotlin, Jetpack Compose, Media3 (`PlaybackService`), Room или Android UI.
     - Целевая директория: `android/app/src/main/java/cord/kasane/music/`
     - Архитектура: `docs/architecture/android.md`
   - **Linux Desktop**: задачи, затрагивающие Svelte 5, Tailwind CSS, Tauri v2 или Rust workspace (`crates/`).
     - Целевая директория: `src/` (frontend) и `crates/`, `src-tauri/` (backend)
     - Архитектура: `docs/architecture/linux.md`
   - **Дизайн и стиль**: общие дизайн-токены и типографика.
     - Спецификация: `docs/design-system.md`

3. **Найди точные файлы через `docs/agent-map.md`**:
   - Открой `docs/agent-map.md`.
   - Найди нужную подсистему и выпиши конкретные классы/файлы (например, `MiniPlayer.kt`, `PlaybackManager.kt` или `crates/vibe-audio`).
   - **Запрещено**: сканировать весь репозиторий рекурсивно через `ls -R` или `find .` без чёткого таргета.

4. **Загрузи минимальный контекст**:
   - Читай **только** целевой файл и связанный с ним интерфейс/тест.
   - Не загружай документацию Android, если задача касается только десктопного Svelte UI, и наоборот.

5. **Переходи к исполнению**:
   - Если требуется изменить UI → активируй навык `kasane-ui`.
   - Если требуется исправить баг → активируй навык `kasane-debug`.
   - Перед завершением задачи → обязательно выполни проверки через `kasane-verify`.
