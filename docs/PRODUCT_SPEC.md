# Продуктовая спецификация

Три уровня достоверности разделены намеренно. Не переноси пункт из нижнего раздела в верхний без
решения владельца.

## 1. Подтверждённые требования

Источник — действующие правила репозитория (`AGENTS.md`, глобальные правила) и прямые указания
владельца в задаче аудита.

- Kasane — музыкальный плеер для Android и Linux desktop; источник музыки — YouTube Music.
- Идентификаторы: `cord.kasane.music` (Android, debug — `.dev`), `cord.kasane.desktop` (desktop).
- Базовое воспроизведение не зависит от AI-провайдера или облачного сервиса Kasane.
- Local-first: локальные треки и закэшированные метаданные доступны без сети.
- Гостевой режим: вход в аккаунт не обязателен.
- Оформление: тёмные угольные поверхности, синий акцент на Android (значения — `docs/design-system.md`), Material 3,
  без «AI-клише» (фиолетовые свечения, псевдостекло, чат-виджеты, моноширинные подписи).
- Данные пользователя на телефоне нельзя терять: никаких деструктивных миграций и тестов на
  личном устройстве (`docs/incidents/android-test-data-loss.md`).
- Секреты (cookie, токены, подписанные URL) не логируются, не экспортируются, не передаются по Connect.
- Клиенты должны сходиться по функциональности; общая логика предпочтительнее дублирования.

## 2. Фактическое поведение (подтверждено кодом, не обязательно требование)

Полный перечень — `FEATURE_MATRIX.md`. Ключевое:

- Выбор трека вне очереди начинает новый контекст и радио от этого трека; выбор коллекции
  сохраняет её порядок (`QueuePolicy`).
- Лимит очереди — 2000 элементов.
- Каждое устройство Connect владеет только своим воспроизведением; общей очереди нет; сопряжение —
  сравнение 6-значного кода, подтверждает принимающая сторона.
- Офлайн на Android: отдельно временный кэш (LRU, лимит задаёт пользователь) и сохранённая музыка
  (не вытесняется); сохраняется только progressive-аудио.
- При недоступности верифицированного потока клиент пробует iOS HLS и сообщает об этом; подставного
  звука не бывает.

## 3. Предположения (записаны в старых документах, владельцем в этом аудите не подтверждены)

Источник — `docs/ROADMAP.md` в редакции от 16.11 (см. git) и `docs/ACCEPTANCE.md`.

- Цель — полный клиент на Kotlin Multiplatform с общим Compose UI; Rust/Tauri удаляется после паритета.
- Локальный режим: импорт папок (SAF на Android), сканирование тегов, локальные плейлисты.
- «Kasane Radio»: локальное ранжирование по фактическому времени прослушивания, без LLM.
- AutoMix: настоящий gapless/crossfade с адаптивным планировщиком.
- Last.fm-скробблинг.
- MPRIS, медиа-клавиши, трей на Linux.
- Управление плейлистами аккаунта: создание, переименование, удаление, перестановка.
- Поддержка Windows упоминается только в `docs/research/desktop-webview.md`.
